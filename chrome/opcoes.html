Token da ponte Fly X-tudo → Fly Studio

A extensão só gera no Fly Studio quando o pedido traz este token. Página nenhuma, nem o próprio X-tudo, consegue ler o token daqui: ele precisa ser colado lá.

Onde colar
  1. No Fly X-tudo do site: Settings › Configurações › Token da ponte › Salvar.
  2. No X-tudo rodando neste PC (localhost:3007 / 127.0.0.1:3007): no arquivo .env.local do site, a linha PONTE_SEGREDO= seguida do token.
